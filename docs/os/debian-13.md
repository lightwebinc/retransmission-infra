# Debian 13 (Trixie)

Debian 13 runs the same task set as [Ubuntu 24.04](ubuntu-24.04.md); service
and file locations on that page apply unchanged. Platform differences (netplan
install, skipped when `manage_netplan: false`; cloud-init networkd; kernel)
are in the canonical [Debian 13 notes](https://github.com/lightwebinc/bsv-multicast/blob/main/docs/infra/os/debian-13.md).
